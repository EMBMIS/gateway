# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: the repository's **Security** tab, then **Report a vulnerability**. Include what is
affected, how to reproduce it, and the impact you expect. You will get an answer within five working days, and we will
keep you informed while it is fixed. We are glad to credit you in the release notes once a fix is out, unless you prefer
not to be named.

## Supported versions

Security fixes go into the latest release on the default branch. Run the latest version.

## Scope

In scope: this repository's code and its default configuration. Out of scope: deployments you run yourself with changed
settings, keys or infrastructure you manage, and third-party services.
